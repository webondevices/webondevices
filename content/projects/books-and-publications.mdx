Explaining something clearly is the best test of whether you really understand it. So I write a lot.

## JavaScript Electronics (2018)

*Beginners guide to building circuits and program electronics with JavaScript, Node.js and Arduino*

The book behind a lot of this site. Over 141 pages, it takes web developers with no electronics background from blinking an LED to building a smart talking plant. Along the way: circuits from first principles, Node.js web, REST and WebSocket servers, sensors for temperature, light, motion and soil moisture, SMS and Twitter notifications, live data charts and speech synthesis.

It holds a 5.0 rating on Amazon.

![JavaScript Electronics](/js-electronics.png)

[JavaScript Electronics on Amazon](https://www.amazon.co.uk/dp/1790464919)

## Introduction to JavaScript Electronics (2018)

The short version: 49 pages you can finish in an afternoon. Run JavaScript outside the browser, wire up an Arduino UNO, switch an LED from code, and read real temperature and light sensors. It's the quickest route from "I'm a web developer" to "I just built a circuit."

![Introduction to JavaScript Electronics](/intro-to-js-electronics.png)

[Introduction to JavaScript Electronics on Amazon](https://www.amazon.co.uk/dp/1790516900)

## All you need is HTML and CSS (2021)

*Building interactive web interfaces with no JavaScript*

221 pages pushing the browser's simplest languages as far as they'll go. Animated carousels, image maps with dismissible popups, an analogue and a digital clock, a calorie counter, a shopping basket, accordions three ways, tabs and a fully working star rating component. None of it uses a line of JavaScript.

Beginners learn that they can build far more than they think. Seasoned JavaScript developers get a reminder that the platform already does a lot of what they reach for libraries to do. Lighter pages, fewer bugs, faster sites. It's the same thinking behind [Stracciatella](/projects/stracciatella-vanilla-js/).

[All you need is HTML and CSS on Amazon](https://www.amazon.co.uk/dp/B08ZQ3NSYF) · [All the book's examples on GitHub](https://github.com/webondevices/html-css-wizardry)
